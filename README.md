# Point3D Print — public demo

Static demonstration of the design and 3D configurator. Includes a browser-only administration simulation with fictional inventory, model and request data. Changes are stored in localStorage only. No real ordering, authentication, inventory records or personal data are hosted here. The full Django application remains in a separate private repository.

Third-party licenses: Three.js MIT in static/vendor/three/LICENSE; Inter OFL in static/fonts/OFL.txt.
